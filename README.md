# Cell Vision

## 1. 프로젝트 소개

**Cell Vision**은 세포 소기관의 구조와 기능을 학습하고, 학습한 생물학적 지식을 활용해 작전을 수행하는 웹 기반 생명과학 학습 프로그램입니다.

특수 작전 게임의 형식을 활용하여 사용자가 대원이 되어 세포 소기관의 정보를 분석하고, 퀴즈와 게임을 통해 학습 내용을 확인하도록 설계했습니다. 이를 통해 단순 암기에서 벗어나 생명과학 개념을 이해하고 실제 문제 해결에 활용할 수 있도록 합니다.

- 개발 환경: Python, Streamlit, HTML, CSS, JavaScript
- 프로젝트 주제: 게임 요소를 활용한 세포 소기관 학습
- 개발 목적: 생명과학 개념의 시각적 이해와 학습 내용의 적용

## 2. 사용법

1. **작전 브리핑 확인:** 메인 화면에서 프로젝트의 배경과 임무 목표를 확인합니다.
2. **세포 소기관 학습:** 각 소기관 페이지에 접속하여 구조와 기능에 관한 정보를 확인합니다.
3. **학습 내용 이해:** 핵, 리보솜, 미토콘드리아, 소포체, 골지체, 리소좀, 세포막, 세포질, 세포골격 등 주요 구성 요소의 특징을 학습합니다.
4. **작전 수행:** 작전 게임에서 생명과학 지식을 활용해 문제를 해결합니다.
5. **결과 확인:** 정답 여부와 작전 결과를 확인합니다.

## 3. 주요 기능

- **세포 소기관 정보 제공:** 세포와 주요 소기관의 이미지 및 생물학적 정보를 통해 구조와 기능을 학습합니다.
- **작전 브리핑:** 특수 작전 콘셉트의 스토리를 활용해 학습 목표와 임무를 제시합니다.
- **인터랙티브 게임:** 문제를 풀고 선택에 따라 게임을 진행하며 학습 내용을 확인합니다.
- **작전 결과 표시:** 게임 종료 후 정답 여부와 임무 성공 여부를 확인할 수 있습니다.
- **통일된 사용자 인터페이스:** 어두운 색상과 작전 지휘실 스타일의 디자인을 적용해 학습 화면과 게임 화면을 하나의 콘셉트로 연결합니다.

## 4. 게임 플레이 방법

1. **작전 브리핑:** 작전 브리핑 페이지에서 작전의 배경과 임무 목표를 확인합니다.
2. **정보 분석:** 메인 화면인 COMMAND CENTER에서 전체 세포 이미지를 확인하고, 9개의 세포 소기관 페이지에 접속해 각 소기관의 구조와 기능을 학습합니다.
3. **작전 시작:** `INITIATE OPERATION` 버튼을 눌러 작전 페이지에 진입하고, 생명과학 퀴즈를 풀어 적의 무결성을 감소시킵니다.
4. **전투 진행:** 플레이어는 체력 4, 적은 무결성 10으로 전투를 시작합니다. 정답을 맞히면 적을 공격하며, 연속 정답 횟수에 따라 첫 번째 정답에는 PULSE RIFLE(피해 1), 두 번째 연속 정답에는 GRENADE(피해 2), 세 번째 연속 정답에는 AIRSTRIKE BOMB(피해 3)이 적용됩니다. 오답을 선택하면 플레이어의 체력이 1 감소하고 연속 정답 횟수가 초기화됩니다.
5. **작전 결과 확인:** 적의 무결성이 0이 되면 작전 성공, 플레이어의 체력이 0이 되면 작전 실패로 처리됩니다. 결과 화면에서 정답과 오답 개수를 확인할 수 있으며, 실패한 경우 재도전하거나 `RETURN TO BASE` 버튼을 통해 메인 화면으로 돌아갈 수 있습니다.
